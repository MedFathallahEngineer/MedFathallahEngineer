## `01` — Beyond writing code

I'm a **Full-Stack Software Engineer and Team Lead** based in Sfax, Tunisia. I build web applications end to end — from system architecture and secure APIs to responsive interfaces, data pipelines, deployment, and production monitoring.

My focus is the engineering behind the interface: maintainable architecture, predictable performance, secure access control, and systems that continue to work long after launch.

Currently, I lead a team of six engineers developing an enterprise business intelligence platform in the mobility sector.

```text
DESIGN  →  ARCHITECT  →  BUILD  →  TEST  →  DEPLOY  →  IMPROVE
```

- **Backend:** Java, Spring Boot, secure REST APIs and distributed services
- **Frontend:** React, TypeScript, data-rich interfaces and interactive dashboards
- **Data:** PostgreSQL, MongoDB, Redis and analytical data models
- **Delivery:** Docker, CI/CD, automated testing, monitoring and production support
- **Leadership:** Technical coordination, code reviews, mentoring and delivery planning

> I don't just want to make software work. I want to understand why it works, how it behaves under pressure, and how to keep it reliable.

## `04` — How I think about engineering

<details>
<summary><b>🏗️ Architecture over shortcuts</b></summary>
<br/>
I aim for clear boundaries, explicit responsibilities and code that can evolve without turning every change into a rewrite. Frameworks are tools; the business logic should remain understandable.
</details>

<details>
<summary><b>⚡ Performance is a feature</b></summary>
<br/>
A dashboard is only useful if people can interact with it. I consider query design, aggregation, caching, payload size and rendering cost when building data-heavy applications.
</details>

<details>
<summary><b>🔐 Security and quality from day one</b></summary>
<br/>
Authentication is only the beginning. Authorization, input validation, automated tests, dependency scanning and deployment checks are part of the development process, not last-minute additions.
</details>

<details>
<summary><b>🤝 Leadership through clarity</b></summary>
<br/>
I translate functional needs into technical specifications, help teams make informed decisions, review code constructively and keep delivery aligned with business priorities.
</details>

<details>
<summary><b>🌐 Collaboration without borders</b></summary>
<br/>
I've collaborated daily with international teams across Tunisia, Türkiye and Serbia, working through technical discussions, shared deliverables, demos and Agile ceremonies.
</details>
